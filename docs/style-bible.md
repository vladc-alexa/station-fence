# Style bible — Greenhouse Dusk

The palette, the rules, and how assets get approved. Generated by
`tools/make_palette.py` — edit the script, not the PNGs.

## 1. Palette (`assets/palette/palette.json`)

45 colours in 12 ramps. Every pixel drawn in the game comes from this file; the
asset pipeline rejects anything else.

| Ramp | Use | Colours |
|---|---|---|
| ink | outlines, HUD plate, deep shadow | #0b0f1a, #141a28, #1e2740 |
| void | space, back wall, night | #101a2b, #16243a, #1d3050, #24405f |
| glass | window frame, dome struts, cool highlights | #2f5670, #3d6f83, #4f8f9a, #6fb3ad |
| soil | floor boards, dirt, pots shadow | #2a1d18, #3b2a20, #4e3828, #63503a |
| leaf | all plant matter (dark to highlight) | #1c4230, #275c3c, #357a49, #4c9a56, #6fbb64, #a3d97e |
| glow | grow lamps, bioluminescence, UI accent | #1b4a4a, #2b7a72, #46b3a0, #86e0c4 |
| bloom | flowers, luxury produce, rare items | #5a1f42, #8d2f5e, #c04b7a, #e87fa3 |
| metal | tools, machines, till, belts | #2b3440, #46515f, #6b7787, #9aa5b1 |
| brass | benches, counter, shelving, warm props | #4a2f1a, #6d4321, #96602f, #c78d4c |
| skin | faces, hands | #3a2630, #6b4a48, #a87a63, #d6a583 |

## 2. Rules

1. **One light direction**: key light from upper-left, cool moonlight from the window.
   Warm brass/signal light only from lamps, never from the left.
2. **Outlines**: 1 px `ink[0]` or `ink[1]` on anything that must read against the floor or wall.
   No outline on interior leaf texture — that is what keeps foliage from looking like wire.
3. **Max 3 tones per material** at 32 px, 4 at 64 px. More tones turn to mush at 4x zoom.
4. **No anti-aliasing.** Nearest-neighbour scaling only (`texture_filter = nearest`).
5. **Dithering** is for light pools and fades only, never for texture noise.
6. **Silhouette first**: every prop must be recognisable as a black shape at 1x.

## 3. Base resolution

- Frame: **480 x 270**, integer-scaled x4 to 1920x1080 (x3 = 1440x810, x5 = 2400x1350).
- Tile grid: 16 x 16. Props align to the grid; plants do not (they overhang).
- Character: 20 x 46 px side view, baseline on the floor line.
- Plant: 16-40 px wide, always drawn with pot; stage 0-3 silhouettes must differ clearly.

## 4. Asset pipeline

```bash
python3 tools/make_palette.py --out assets/palette          # palette + swatch + look-dev
python3 tools/asset_pipeline.py --src assets/raw --out assets/gen --grid 32 --scale 8
```

`asset_pipeline.py` keys the background, resamples to the grid, quantises to the
nearest palette colour, and writes `atlas.png` + `atlas.json`. Anything that comes back
with colours outside the palette is a bug in the palette, not in the art.

## 5. Sign-off checklist for a new asset

- [ ] Only palette colours (verified by the pipeline).
- [ ] Reads at 1x without zoom.
- [ ] Outline matches the material rules above.
- [ ] Sits correctly on the 16 px grid and on the bench/counter baselines.
- [ ] One highlight, one shadow — no pillow shading.
